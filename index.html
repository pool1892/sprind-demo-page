Transcript

The narration, beat by beat; the same words are the captions in the picture.

0:00 Opening. This is a simulated robot installation: one robot arm at a kitchen table. Its policy, the model that turns camera images into motion, is fixed. Agents watch the installation, run experiments on it, and change how the installation uses that policy.

0:18 Story A. First story: make this one job.

0:22 The skills. The robot already has skills. Each skill is one task on this table, done by the policy under its own instruction. Here, each one runs alone and delivers. The policy does not change anywhere in this film.

0:39 The request. A shift lead asks for one job: two skills in a row, ending in a stated arrangement. The lead adds a rule about the order. The agent proposes the bar: the job must deliver on at least 18 of 20 fresh starts it was never run on. The lead approves that bar before any program is tested.

1:05 The naive attempt. The obvious chain switches to the next skill the moment the first one reports success. That is the signal published scores count. But it can fire while the hand still holds the item, and the arrangement ends wrong. On the {release_n} reserved starts, the obvious chain delivers on {release_naive_delivered}. A success signal is not a delivery.

1:30 The investigation. The agent reads the object traces and writes its own check: did a later step undo an earlier one, and is everything released and at rest? It finds the failing moment. Then it tests transitions on the installation itself, 2 development starts in all.

1:50 The release. The agent freezes its program and runs it on {release_n} reserved starts it has never seen. It delivers on {release_delivered}; the bar was {release_k}. The obvious chain, on the same starts, delivers on {release_naive_delivered}. Rescued: {release_rescued}. Broken: {release_broken}. Then the agent explains the change to the shift lead in plain words.

2:13 The next shift. The job and the check join the installation's job list, and an operator runs the job with one command from a fresh start. Then a second request arrives. The agent runs the saved check and reuses its method. Job one took 1 sessions, 2 simulated starts and 1 minutes of the agent's model time. Job two took {job_two_sessions} sessions, {job_two_starts} starts and {job_two_model_minutes} minutes.

2:42 What changed. The robot policy stayed the same. The installation gained {library_jobs} jobs and a check it did not have this morning.

2:52 The record. Every clip in this film is a recorded run. The record lists each one.
